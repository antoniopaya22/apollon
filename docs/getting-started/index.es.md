# Primeros pasos

Apollon es un paquete de Python (`apollon`) con una interfaz de línea de comandos (`apollon`).
Funciona con cualquier conjunto de características tabulares de flujos e incluye cargadores
para los conjuntos de datos CIC utilizados en el artículo.

1. [Instala](installation.md) el paquete, opcionalmente con las herramientas de ataques adversarios.
2. Sigue la [guía rápida](quickstart.md): entrena y evalúa Apollon con tráfico sintético
   y, después, con un conjunto de datos real.
3. Lee [cómo funciona Apollon](../guide/how-it-works.md) para ajustarlo a tu tráfico.
