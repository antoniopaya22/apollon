# Getting started

Apollon is a Python package (`apollon`) with a command line interface (`apollon`). It
works on any tabular flow features, and ships loaders for the CIC datasets used in the
paper.

1. [Install](installation.md) the package, optionally with the adversarial attack tools.
2. Run the [quickstart](quickstart.md): train and evaluate Apollon on synthetic
   traffic, then on a real dataset.
3. Read [how Apollon works](../guide/how-it-works.md) to tune it for your traffic.
