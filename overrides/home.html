Computers & Security · vol. 136 · 2024

An IDS that never
shows the same face twice

Apollon defends machine-learning intrusion detection against adversarial attacks. Every request is answered by a classifier drawn from a diverse pool by a Multi-Armed Bandit with Thompson sampling, so attackers cannot learn a stable boundary to evade, and detection stays accurate.

The problem

Black-box attacks learn a fixed boundary.
Apollon keeps moving it.

ZOO and HopSkipJump query the IDS, estimate where its decision boundary lies and push an attack just across it. That works when the same model answers every query. With Apollon, consecutive queries can be answered by different classifiers, so the attacker's estimates never converge.

How it works

Three ideas, one draw per request

01

Cluster the traffic

K-Means groups requests, and every classifier is trained on every cluster: each kind of traffic gets its own specialised pool.

02

Sample, don't choose

Each (cluster, classifier) keeps a Beta posterior of its accuracy. For every request one value is drawn per classifier and the highest draw answers.

03

Keep learning

Analyst feedback updates the posteriors online, so the classifiers that are right on today's traffic answer more often tomorrow.

from apollon import ApollonMAB
from apollon.data import prepare

data = prepare("cic-ids2017", ["data/CIC-IDS2017/"])
model = ApollonMAB(random_state=0).fit(data.X_train, data.y_train)

# one Thompson draw per request
